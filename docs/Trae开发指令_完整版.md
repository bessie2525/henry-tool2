请阅读项目根目录下的 `PRD.md` 文件，这是「学伴精灵」微信小程序的完整产品设计文档（v2.0）。请严格按照文档中的功能设计、数据结构、API 接口和技术架构，帮我从零完成这个微信小程序的全部开发。

### 项目概述

这是一个面向 6-12 岁儿童的学习任务管理微信小程序，核心玩法是「虚拟宠物养成 + 学习任务」。孩子通过完成学习任务获取金币来喂养和装扮宠物。包含学生端和家长端两个视角，使用同一个小程序通过角色切换进入。

技术栈：**微信小程序原生框架 + 微信云开发（CloudBase）**。

### 开发注意事项

1. **安全第一**：所有金币变更、任务状态变更必须在云函数端完成，前端不可直接修改数据库
2. **数据隔离**：严格配置数据库安全规则，学生只能访问自己的数据
3. **宠物状态实时计算**：宠物的饱食度、口渴度不需要实时写数据库，查询时根据 `lastFedAt` + 衰减速率动态计算
4. **AI 接口安全**：AI API Key 存储在云函数环境变量中，不暴露在前端代码中
5. **分包加载**：学生端和家长端使用小程序分包，减少首屏加载时间
6. **英语 TTS**：使用 `wx.createInnerAudioContext()` 播放音频，单词发音可使用免费 TTS API 预生成
7. **图片资源**：宠物图片用 SVG 或精灵图，减少网络请求；后续可替换为设计师提供的正式素材
8. **代码规范**：
   - 使用 ES6+ 语法
   - 云函数使用 async/await
   - 组件化开发，公共逻辑抽取到 utils
   - 每个云函数入口做参数校验
9. **错误处理**：所有 API 调用需有 loading 状态和错误提示
10. **可扩展性**：PRD 中标注了大量扩展预留接口，代码中请用枚举/配置的方式定义任务类型、商品类型等，方便后续扩展
