## 一、产品概述

### 1.1 产品定位

「学伴精灵」是一款面向 **6-12 岁儿童**的学习任务管理微信小程序，以 **虚拟宠物养成** 为核心驱动力，将日常学习任务（语文积累、英语单词、日常打卡）与宠物成长体系深度绑定。孩子通过完成学习任务获取金币，用金币喂养、装扮、培育自己的专属宠物，在「玩中学、学中玩」的正向循环中养成良好学习习惯。

### 1.2 核心设计原则

| 原则 | 说明 |
|------|------|
| **趣味驱动** | 宠物养成为主线，学习任务为支线，孩子的第一感受是「养宠物」而非「做作业」 |
| **家长可控** | 家长拥有任务编排、内容审核、数据查看的完整管控能力 |
| **简单易用** | 10 岁孩子可独立操作，核心流程 ≤3 步完成 |
| **可持续扩展** | 模块化架构，预留任务类型、宠物物种、社交玩法等扩展接口 |

### 1.3 用户角色

| 角色 | 说明 |
|------|------|
| **学生（孩子）** | 小程序的核心使用者，养宠物 + 完成任务 |
| **家长** | 任务管理者、审核者，可有多位家长绑定同一个孩子 |

### 1.4 账号体系

- 每个 **学生** 拥有一个独立账号（微信授权登录后创建）
- 每个学生账号可绑定 **多个家长**（通过邀请码/扫码绑定）
- 家长可管理 **多个孩子**（切换孩子视图）
- 家长与学生使用 **同一个小程序**，通过角色切换进入不同端

## 三、核心功能模块详细设计

### 3.1 宠物养成系统（学生端核心）

#### 3.1.1 宠物创建

| 要素 | 说明 |
|------|------|
| **触发时机** | 学生首次进入小程序时 |
| **流程** | 选择宠物物种 → 给宠物起名字 → 选择初始颜色 → 进入主页 |
| **初始物种** | V1.0 提供 3 种：小猫、小狗、小龙（后续可扩展） |
| **命名规则** | 2-6 个字符，支持中英文，禁敏感词 |

#### 3.1.2 宠物属性系统

```
宠物数据模型：
{
  petId: string,           // 宠物唯一ID
  name: string,            // 宠物名称
  species: string,         // 物种（cat/dog/dragon/...）
  level: number,           // 等级（1-100）
  exp: number,             // 当前经验值
  expToNextLevel: number,  // 升级所需经验值
  
  // === 状态值（0-100，每日自然衰减） ===
  hunger: number,          // 饱食度（每6小时 -10，降为0宠物会「生病」）
  thirst: number,          // 口渴度（每4小时 -10）
  mood: number,            // 心情值（完成任务+20，与宠物互动+5，每天不登录-30）
  
  // === 外观 ===
  skinId: string,          // 当前皮肤
  accessoryIds: string[],  // 当前佩戴的装饰
  sceneId: string,         // 当前场景/背景
  
  // === 成长记录 ===
  createdAt: timestamp,
  totalDaysActive: number, // 总活跃天数
  consecutiveDays: number, // 连续登录天数
}
```

#### 3.1.3 宠物互动

| 互动类型 | 操作方式 | 效果 | 消耗 |
|----------|----------|------|------|
| **喂食** | 点击食物拖到宠物嘴边 | 饱食度 +20~50（取决于食物品质） | 金币购买食物 |
| **喂水** | 点击水杯拖到宠物 | 口渴度 +30 | 免费（每日3次），高级饮品消耗金币 |
| **抚摸** | 手指在宠物身上滑动 | 心情 +5，播放开心动画 | 免费（每日5次） |
| **对话** | 点击聊天气泡进入对话界面 | 心情 +3，获取学习鼓励 | 免费 |
| **换装** | 进入衣柜选择皮肤/装饰 | 外观改变，部分皮肤附带属性加成 | 需先购买 |

#### 3.1.4 宠物成长机制

- **经验值获取**：
  - 完成语文任务：+30 EXP
  - 完成英语任务：+30 EXP
  - 完成日常打卡（每项）：+15 EXP
  - 连续登录加成：连续 N 天，当日经验 ×(1 + N×0.05)，上限 ×2.0
- **等级系统**：
  - 每 5 级宠物外观发生一次进化变化（更大、更精致）
  - 关键进化节点：Lv.10 / Lv.25 / Lv.50 / Lv.100
  - 进化时播放特效动画，增强仪式感
- **状态衰减**：
  - 宠物状态每日自然衰减，激励孩子每天登录照顾宠物
  - 若连续 3 天不登录，宠物进入「想念主人」状态，显示难过表情
  - 回归后宠物表现出惊喜，给予回归奖励

#### 3.1.5 宠物 AI 对话（聊天系统）

| 要素 | 说明 |
|------|------|
| **对话入口** | 宠物主页点击宠物的聊天气泡 |
| **对话风格** | 宠物以第一人称、可爱萌系口吻与孩子交流 |
| **核心功能** | 日常闲聊、学习鼓励（"主人今天的任务完成得真棒！"）、简单知识问答 |
| **安全机制** | 内容过滤 + 敏感词拦截，仅输出适合儿童的正面内容 |
| **技术方案** | 接入大语言模型 API（如豆包/ChatGPT），配合角色提示词定制宠物人格 |
| **对话次数** | 每日免费 20 条，可用金币解锁额外次数 |

**宠物人格 Prompt 模板**：
```
你是一只名叫{petName}的{species}，你的主人是一个10岁的小男孩。
你性格活泼可爱，说话简短有趣，喜欢用颜文字。
你会鼓励主人学习，夸奖他的进步，在他遇到困难时安慰他。
你的回复要简短（不超过50个字），适合10岁孩子理解。
不要涉及任何负面、暴力、成人内容。
当主人完成任务时要特别开心地夸奖他。
```

### 3.3 学习任务模块

#### 3.3.1 语文每日一记

**定位**：培养孩子的文字表达和阅读积累习惯，每天 2-3 分钟即可完成。

**学生端交互流程**：

```
进入任务 → 看到今日主题提示（可选） → 输入文字内容 → 点击提交 → 等待家长审核
```

**详细设计**：

| 要素 | 说明 |
|------|------|
| **任务入口** | 任务中心 → 「语文每日一记」卡片 |
| **每日主题（可选）** | 家长可设置引导主题（如"今天读了什么书？""用一句话描述今天的心情"），也可让孩子自由发挥 |
| **输入方式** | 文字输入框，最少 10 字，最多 200 字 |
| **辅助功能** | 语音输入转文字（降低打字门槛） |
| **提交后** | 状态变为「待审核」，家长审核通过后获得金币 |
| **历史记录** | 可查看过往所有每日一记，形成孩子的「成长日记」 |

**数据模型**：
```
{
  taskId: string,
  type: "chinese_daily",
  studentId: string,
  date: string,            // 日期 YYYY-MM-DD
  topic: string,           // 当日主题（家长设置）
  content: string,         // 孩子提交的文字
  voiceUrl: string,        // 语音输入的原始音频（可选）
  status: "pending" | "submitted" | "approved" | "rejected",
  reviewerId: string,      // 审核家长ID
  reviewComment: string,   // 家长评语
  coinReward: number,      // 获得的金币
  createdAt: timestamp,
  reviewedAt: timestamp,
}
```

#### 3.3.2 英语学习冒险模块（升级版）

**定位**：围绕 **"单词 → 例句 → 场景"** 三层递进的完整学习闭环，以宠物冒险闯关为故事包装，让孩子在玩的过程中自然吸收英语知识。每日约 10-15 分钟。

**每日学习流程**：

```
📖 学习岛（认识单词）→ 🎮 游戏大冒险（5选3闯关+Boss）→ 📝 例句工坊（复习强化）→ 🏆 结算奖励
     约3分钟              约5-8分钟                    约2-3分钟            即时
```

##### 一、学习岛（单词认识）

用卡片翻转 + 沉浸式动画的方式，让孩子初步认识今日单词。每个单词包含：

| 展示内容 | 说明 |
|----------|------|
| 单词 + 音标 | 英文单词及国际音标 |
| 发音播放 | 点击播放标准发音（TTS） |
| 配图 | 单词对应的插画 |
| 中文释义 | 简明中文解释 |
| 例句 | 简单英文例句 + 中文翻译 + 例句发音 |
| 记忆小妙招 | 助记提示（家长可自定义，系统提供默认） |

```
┌─────────────────────────────────┐
│  📖 学习岛        3/10          │
├─────────────────────────────────┤
│  ┌─────────────────────────┐    │
│  │       🍎                │    │
│  │      apple              │    │
│  │     /ˈæpəl/   🔊        │    │
│  │     名词 · 苹果          │    │
│  │  ───────────────────    │    │
│  │  📝 例句：               │    │
│  │  I eat a red apple      │    │
│  │  every morning.         │    │
│  │  我每天早上吃一个红苹果。  │    │
│  │  🔊 听例句发音            │    │
│  │  ───────────────────    │    │
│  │  💡 记忆小妙招：          │    │
│  │  apple 的 "a" 像苹果     │    │
│  │  上面的叶子~              │    │
│  └─────────────────────────┘    │
│   [← 上一个]  [⭐收藏] [下一个 →] │
│   [🎮 我学好了，开始冒险!]        │
└─────────────────────────────────┘
```

**功能要点**：
- 卡片翻转动画（正面英文+图片，背面中文+例句）
- 收藏标记（标记难词，方便后续重点复习）
- 浏览进度（顶部显示 3/10），所有单词浏览完后解锁游戏入口
- 记录每个单词停留时间，帮助家长了解薄弱点

##### 二、游戏大冒险（核心游戏区）

以 **「宠物冒险闯关」** 为故事包装：宠物需要穿越不同关卡，孩子帮助宠物答题通关。每日从 5 种游戏中随机选 3 关 + 1 个 Boss 关：

```
🏝️ 出发 → 🎮 第1关 → 🎮 第2关 → 🎮 第3关 → 👑 Boss关 → 🏆 胜利!
```

**游戏一：🌊 单词漂流瓶**

海面上漂来多个瓶子，每个瓶子里有一个英文单词。屏幕上方显示中文释义，孩子点击正确的漂流瓶。

```
┌─────────────────────────────────┐
│  🌊 单词漂流瓶     第1关         │
│  ⏱ 00:30   ❤️❤️❤️   得分: 40   │
├─────────────────────────────────┤
│         🐱（宠物站在岸边）        │
│    请找到「苹果」的漂流瓶!        │
│  🌊🌊🌊🌊🌊🌊🌊🌊🌊🌊🌊🌊       │
│    🍶apple   🍶grape            │
│         🍶banana                │
│    🍶orange       🍶peach       │
│  🌊🌊🌊🌊🌊🌊🌊🌊🌊🌊🌊🌊       │
│  答对: 宠物跳跃 + 瓶子发光 ✨     │
│  答错: 瓶子碎裂 + 显示正确答案    │
└─────────────────────────────────┘
```

- 漂流瓶在海面上随机漂动，需快速识别点击
- 连续答对 3 题触发「连击」特效
- 偶尔漂来「金色瓶子」（加分题），答对双倍积分

## 八、宠物动画与视觉设计指南

### 8.1 宠物动画状态

| 状态 | 触发条件 | 动画描述 |
|------|----------|----------|
| `idle` | 默认状态 | 宠物原地小幅摆动、偶尔眨眼 |
| `happy` | 完成任务/抚摸 | 跳跃 + 冒爱心 |
| `eating` | 喂食时 | 张嘴吃东西的咀嚼动作 |
| `drinking` | 喂水时 | 喝水动作 |
| `sad` | 状态值过低 | 耷拉耳朵、泪眼汪汪 |
| `sick` | 饱食度为 0 | 头顶冒螺旋、面色发青 |
| `sleeping` | 晚10点至早6点访问 | 闭眼 + zzZ 气泡 |
| `excited` | 升级/获得成就 | 发光特效 + 欢呼动画 |
| `miss` | 3天未登录 | 趴在地上、头顶问号 |
| `levelup` | 升级时 | 光柱特效 + 外观渐变为新等级形象 |

### 8.2 视觉风格

- **整体风格**：Q 版卡通、圆润线条、明亮配色
- **主色调**：天蓝 + 暖黄 + 草绿（活力感）
- **字体**：圆体字（如「仓耳渔阳体」或系统圆体），可爱友好
- **宠物设计**：大眼睛、大头小身、表情丰富，参考《旅行青蛙》和 Tamagotchi 风格
- **UI 设计**：大按钮、大间距、适合儿童手指操作（最小触控区域 44×44 pt）

## 十二、安全与合规

| 事项 | 措施 |
|------|------|
| **儿童隐私** | 遵循《儿童个人信息网络保护规定》，最小化收集信息 |

| **金币安全** | 金币变更通过云函数处理，前端不可直接修改 |

## 十四、开发注意事项（给 Trae 的补充说明）

1. **云开发初始化**：需在 `app.js` 中调用 `wx.cloud.init({ env: 'your-env-id' })`
2. **数据安全规则**：云数据库需配置安全规则，确保学生只能读写自己的数据，家长只能访问绑定孩子的数据
3. **宠物状态实时计算**：宠物的饱食度、口渴度不需要实时写数据库，可以在查询时根据 `lastFedAt` + 衰减速率动态计算
4. **图片资源**：宠物图片建议使用精灵图（Sprite Sheet）或 Lottie JSON 动画，减少网络请求
5. **防刷机制**：金币获取必须在云函数端校验，前端不可传入金币数量
6. **英语 TTS**：可使用微信小程序 `wx.createInnerAudioContext()` 播放预生成的音频文件，或调用 Web Speech API
7. **AI 对话**：建议将 AI API Key 存储在云函数环境变量中，不要暴露在前端
8. **分包加载**：学生端和家长端建议使用小程序分包加载，减少首屏加载时间
9. **骨架屏**：主要页面添加骨架屏，提升加载体验
10. **无障碍**：按钮和操作区域最小 44×44 pt，适合儿童手指操作
